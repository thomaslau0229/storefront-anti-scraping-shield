# Changelog

All notable public changes are documented here.

## 0.2.0

- Renamed the project to Storefront Anti-Scraping Shield.
- Added architecture, configuration, deployment, API, and threat-model documentation.
- Added a neutral browser integration example.
- Added continuous integration and contributor guidance.
- Preserved the existing minimal decision runtime and privacy boundary.

## 0.1.0

- Added a minimal Cloudflare Worker and browser runtime.
- Added exact-origin CORS and route classification.
- Added anonymous HMAC correlation keys and D1 event storage.
- Added `log_only`, fail-open behavior, exact HTTPS redirect configuration, tests, and publication validation.
