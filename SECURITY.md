# Security Policy

Report security issues privately to the repository maintainers with a minimal reproducible description, affected version, impact assessment, and steps that do not disclose private data or credentials.

Only test systems and networks for which you have explicit authorization. Do not target third-party deployments, access private data, collect credentials, or perform disruptive testing.

Do not include raw IP addresses, browser identifiers, event exports, Worker secrets, account identifiers, or live configuration in a report. Use reserved example values and redact deployment-specific evidence.

Supported security fixes are released against the current minor version. Older examples may remain visible for historical review but should not be treated as maintained deployment guidance.
